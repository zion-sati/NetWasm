# Security policy

NetWasm is pre-1.0 and has not undergone an independent security audit. Its
compiler, runtime ABI, CoreLib profile, generated host adapters, and supported
capability set may change between minor releases. Security-sensitive deployments
need their own review of the exact pinned toolchain, host and granted capabilities.

## Reporting

Do not publish exploit details in a public issue. Use the repository host's
private vulnerability-reporting feature when it is enabled for this repository.
If that feature is unavailable, no private reporting channel has been published
yet; maintainers must establish one before making a production-support claim.

There is currently no response-time commitment, supported-version policy,
security-fix backport policy, or bounty programme. This file will be updated
when those commitments exist.
