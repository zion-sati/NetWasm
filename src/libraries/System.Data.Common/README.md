# NetWasm.System.Data.Common

`NetWasm.System.Data.Common` supplies the `System.Data.Common` assembly for the
`netwasm0.1` profile: DataSet, DataTable, DataView and their XML reading and
writing, the ADO.NET provider base classes, and System.Data.SqlTypes. It is an
independently versioned ported-library package for applications that opt into
the NetWasm data surface.

The package carries the `NetWasm,Version=v0.1` asset and preserves the public
`System.Data.Common` assembly identity. The package targets only `netwasm0.1`.
It does not include a database provider.
