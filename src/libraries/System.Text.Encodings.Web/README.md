# NetWasm.System.Text.Encodings.Web

`NetWasm.System.Text.Encodings.Web` supplies the `System.Text.Encodings.Web`
assembly for the `netwasm0.1` profile. It preserves the standard assembly
identity while packaging the NetWasm implementation under the non-conflicting
NetWasm package ID.

Reference this package from a `netwasm0.1` project. It supplies the library
asset for that profile.
